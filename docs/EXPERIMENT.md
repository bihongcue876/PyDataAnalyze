# 1. 交互式数据分析系统

## 一、实验基本信息

*   **实验名称**：文件数据分析与可视化综合应用（交互式数据分析系统开发）
*   **组队要求**：5-6 人/组，明确角色分工

---

## 二、实验目标

### 1. 能力培养
本次实验旨在培养同学们运用 Python 进行数据分析系统开发的能力。重点包括：
*   **数据处理**：掌握使用 Pandas 进行数据加载、清洗和基础分析的核心技能，能够针对不同数据类型选择合适的可视化方法；
*   **算法集成**：理解如何将机器学习算法（如 K-Means 聚类或线性回归）封装为 Web 服务，实现从数据输入到分析结果展示的完整流程；
*   **系统开发**：通过 Flask/Django 等 Web 框架的开发实践，掌握前后端交互、API 设计和基础系统架构的能力。

### 2. 成果要求
1.  **系统开发**：开发可通过 Web 页面操作的数据分析系统，系统需包含完整数据处理流程：`上传` $\rightarrow$ `清洗` $\rightarrow$ `分析` $\rightarrow$ `可视化` $\rightarrow$ `导出`。
2.  **个人文档**：每位同学需提交个人成果展示文档，内容包括：系统分析与设计、系统整体功能模块描述、负责的功能模块详细说明（含实现思路和主要代码片段）、系统运行截图、遇到的典型问题及解决方案、个人收获与改进建议。文档要求结构清晰，重点突出技术实现细节和个人贡献。

---

## 三、功能要求

| 模块 | 必做要求 | 扩展建议（加分项） |
| :--- | :--- | :--- |
| **数据管理** | 支持 CSV/Excel 等文件上传、预览、导出 | 数据库集成（SQLite/MySQL） |
| **数据清洗** | 缺失值处理、异常值检测 | 自动化清洗规则配置 |
| **可视化** | 动态生成 3 种以上图表 | 用户自定义图表参数 |
| **分析功能** | 至少实现 1 种分析（聚类/预测/分类/降维） | 多算法对比 + 效果评估 |
| **Web 界面** | 响应式布局，基础交互 | 多用户登录、历史记录存储、检索等管理功能 |

*   **基础功能（30分）**：数据上传、清洗、可视化、导出功能完整。

## 五、数据获取指南

可从以下渠道获取实验数据：

1.  **Kaggle 数据集（推荐）**：访问 [Kaggle 官网](https://www.kaggle.com/)，搜索关键词（如 movies、sales、weather），选择 CSV/Excel 格式的小型数据集（小于 10MB）直接下载使用。
2.  **公开 API（免爬虫）**：如国家统计局、Alpha Vantage（股票数据）等，通过 API 请求直接获取结构化数据。
3.  **简易爬虫（可选）**：针对 Wikipedia 表格、新浪财经等无反爬限制的网站，使用 `pandas.read_html` 或 `requests` + `BeautifulSoup` 提取数据。
4.  **自主生成（测试用）**：使用 `numpy` 或 `pandas` 快速生成模拟数据（如随机销量、日期序列等）。
